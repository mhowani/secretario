# Secretario

Página web para el secretario de la congregación: informes mensuales, asistencia a las reuniones,
precursores, estadísticas y los formularios S-1, S-3, S-10, S-21 y S-88 rellenados sobre los PDF oficiales.

- **Los datos no salen del dispositivo.** No hay servidor ni cuenta: todo se guarda en el navegador.
  Haz copias de seguridad (Ajustes › Exportar copia) en iCloud Drive.
- **Los formularios oficiales no están en este repositorio.** La primera vez se cargan desde el
  dispositivo (Ajustes › Formularios oficiales) y se guardan solo allí.
- La copia de seguridad (.json) tiene el mismo formato que la app de Xcode, así que se pueden pasar
  los datos de una a otra.

En iPhone y iPad: ábrela en Safari › Compartir › **Añadir a pantalla de inicio**, y úsala siempre desde ese icono.
